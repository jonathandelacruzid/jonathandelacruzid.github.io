Transforming a raw HR dataset into a clean, fully numeric, machine-learning-ready file in Python — part of how I keep building the data and AI skills my team relies on.

Why it matters

Data fluency is part of the job.

Instructional design runs on data: survey results, learner metrics, completion and program reporting. At work, I build that reporting in Excel. To bring more rigor to it, I pursue challenging coursework in Python, machine learning and data preparation, then apply it to real datasets. This project, from my graduate Learning Technologies coursework, takes a messy public HR dataset and prepares it for a model that predicts which data scientists will look for a new job.

The pipeline

Clean.
Engineer.
Encode.

  1. Profile the raw data

    Loaded the dataset in Python with pandas in Google Colab and profiled its gaps — including 5,938 missing company-size values and 4,508 missing gender values.

  2. Impute with intent

    Filled lightly missing fields (gender, university enrollment, education level) with each column’s most frequent value, and gave heavily missing fields (major, company size, company type) an explicit “Missing” category so the gap itself stays visible to a model.

  3. Engineer features

    Converted text ranges such as “<1”, “>20”, “never” and “>4” into numbers, then created an experience-level feature: Entry (0–5 years), Mid (6–10), Senior (11–15) and Expert (16+).

  4. Format for modeling

    Removed non-predictive columns (ID, city and raw experience) and one-hot encoded eight categorical features, producing a 36-column, fully numeric dataset with no missing values — ready to train a model.
