Crafting Effective
AI Prompts

A narrated Storyline course on AI prompting for a correctional reentry program, featuring a JavaScript simulation that grades learners’ prompts with no model access or API key required.

The engagement

AI literacy for reentry.

Our EdTech startup secured a short-term contract with a prison system to deliver AI fundamentals through its reentry program, in which incarcerated individuals within a year of release complete coursework that prepares them for life after release. This narrated Storyline course, the second in the AI upskilling campaign, taught learners a five-step checklist for writing effective prompts, then let them practice it.

The constraint

No model.
No API key.

  1. Design for the worst case

    We could not confirm whether the learning environment had access to AI models, so the course was designed for the most restrictive scenario: none.

  2. Simulate instead of connect

    In place of an API connection, I built a JavaScript engine inside Storyline that evaluates each learner’s prompt against defined criteria and returns a grade.

  3. Make the scoring visible

    Learners saw example criteria and how the score was formulated, so they understood exactly how each grade was earned.

  4. Make it feel real

    Feedback types out character by character, like a live AI response, so practice felt authentic without a live model behind it.

How the grader works

Four prompting strategies

Each prompt is scored on a clear task instruction, reference text or examples, step-by-step structure, and a request for the AI to explain its reasoning, at two points each on an eight-point scale.

Letter grades

Scores map to grades A through D. Prompts under ten characters are returned for revision with worked examples, including math-specific examples when a prompt is mostly numbers.

Targeted, varied feedback

Each missing strategy generates a specific tip, vague words such as “thing” or “stuff” are flagged in an annotated copy of the prompt, and feedback rotates across five variations per grade so repeat attempts never feel scripted.

Storyline and JavaScript in tandem

JavaScript reads the learner’s prompt from a Storyline variable, grades it, and writes the grade and feedback back to Storyline for display; a reset script clears everything for another attempt.

The business impact

Value delivered

Contract support

Delivered the second course in the AI upskilling campaign, supporting the startup’s contract to bring AI fundamentals to a correctional reentry program.

No barriers

With no model access, API key or external service required, the course runs in the most restrictive environment, removing a dependency the client could not confirm.

Applied skill

Learners practiced writing prompts with instant, transparent grading, turning a five-step checklist into a practical skill for life after release.

Role and contribution

Instructional Design · Storyline 360 Development · JavaScript · Assessment Design

Designed and built the course and its prompt-grading simulation end to end: the scoring rubric, the JavaScript engine, the feedback library and the Storyline integration. As a rules-based system, the grader rewards the patterns it was designed to detect rather than interpreting intent the way a model would; in an environment without model access, that trade-off delivered a consistent, transparent practice experience.
