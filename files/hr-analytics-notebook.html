Part 2: Data Cleaning & Imputation Strategies

Your primary goal in this section is to handle all missing data. Each group of columns requires a different strategy.

Task 2.1: Impute Columns with Few Missing Values

  • Requirement 1: For the gender, enrolled_university, and education_level columns, all missing values must be filled.
  • Requirement 2: The value used for filling must be the mode (the most frequent value) of each respective column.

Task 2.2: Impute Columns with Many Missing Values

  • Requirement 1: For the major_discipline, company_size, and company_type columns, all missing values must be filled.
  • Requirement 2: The value used for filling must be the literal string 'Missing'.

Task 2.3: Impute Columns to Prepare for Numeric Conversion

  • Requirement 1: All missing values in the experience column must be filled with the string '0'.
  • Requirement 2: All missing values in the last_new_job column must be filled with the number 0.

In [3]

# Task 2.1: impute categorical features with their mode
for col in ['gender', 'enrolled_university', 'education_level']:
  mode_val = df[col].mode()[0]
  df[col] = df[col].fillna(mode_val)

# Task 2.2: Fill features with many missing values with a "Missing" category
for col in ['major_discipline', 'company_size', 'company_type']:
  df[col] = df[col].fillna('Missing')

# Task 2.3: Fill in missing 'last_new_job' and 'experience' values
df['last_new_job'] =df['last_new_job'].fillna(0)
df['experience'] = df ['experience'].fillna(0)

Part 3: Feature Engineering

Create new, more useful features by cleaning and transforming existing columns.

Task 3.1: Clean the experience Column

  • Requirement 1: The final experience column must be of a numeric data type (e.g., integer or float).
  • Requirement 2: All instances of the string '<1' must be converted to the number 0.
  • Requirement 3: All instances of the string '>20' must be converted to the number 21.

Task 3.2: Clean the last_new_job Column

  • Requirement 1: The final last_new_job column must be of a numeric data type.
  • Requirement 2: All instances of the string 'never' must be converted to the number 0.
  • Requirement 3: All instances of the string '>4' must be converted to the number 5.

Task 3.3: Create the experience_level Feature

  • Requirement 1: You must create a new column named experience_level.
  • Requirement 2: This column must contain categorical data derived from the cleaned experience column.
  • Requirement 3: The categories must map to the following numerical ranges:

'Entry': 0-5 years of experience. 'Mid': 6-10 years of experience. 'Senior': 11-15 years of experience. 'Expert': 16 or more years of experience.

In [4]

Part 4: Final Formatting for Modeling

This is the final preparation step to make our dataset ready for a machine learning algorithm. Our goals are to remove any information that isn't useful for prediction and to convert all our data into a purely numerical format, which is a requirement for most models.

Task 4.1: Drop Unnecessary Columns

  • Requirement 1: The enrollee_id and city columns must be removed. enrollee_id is a unique identifier with no predictive value, and city has too many unique categories to be easily used in a model.
  • Requirement 2: The original experience column must be removed, as it has been replaced by the more useful experience_level feature.

Task 4.2: One-Hot Encode Categorical Features

  • Requirement 1: All remaining columns with text or categorical data must be converted into a numeric format using the One-Hot Encoding technique.
  • Requirement 2: This technique should be applied to the following columns: gender, relevent_experience, enrolled_university, education_level, major_discipline, company_size, company_type, and experience_level.
  • Requirement 3: Use the drop_first=True parameter during encoding to avoid redundant columns.
